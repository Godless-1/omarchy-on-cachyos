# v1.4.7.1 - Discerning Dratini

Explicit upgrades now check GitHub every time. Previously, `ooc update` could reuse a cache less than a day old and incorrectly report that the installed version was current. If GitHub cannot be checked, the command now fails clearly without installing anything. Startup notifications remain cache-only.

## Upgrade from an affected version

Save your work and close Omarchy windows. In Plasma, run:

```bash
ooc updates --refresh && ooc update --no-restart
```

The refresh must succeed before continuing. After installation, `pacman -Q omarchy-on-cachyos` should report `1.4.7.1-1`. Future explicit upgrades refresh automatically.

The updater suite now has 24 checks, including a fresh but outdated cache and an unreachable GitHub API. This patch retains all 1.4.7 recovery fixes and its documented limitations. It does not modify boot configuration or erase historical privacy exposure.
