# v1.4.7 - Diligent Dratini

> **In development.** Automated checks pass for the cases exercised; complete rollback, successful reboot and all interactive desktop behavior are not guaranteed.

1.4.7 maps to National Pokédex #147, Dratini. This release concentrates on recovery and accurate documentation. Both the Plasma window and the dedicated Omarchy session continue to use existing files and installed applications. No VM is required.

## Recovery fixes

- Uninstall now stops if package removal fails, the package database cannot be read, or packages remain after reported success. Repository and guards remain available for recovery. Failed package removal also leaves session files intact.
- Both Omarchy packages are removed in one nonrecursive transaction. A dependency conflict stops removal instead of silently proceeding or recursively removing other applications.
- `ooc uninstall --keep-apps` retains the repository and safeguards along with the packages.
- Dry-run preserves an empty skills directory and does not request sudo authentication.
- `ooc preserve-identity --undo-branding` restores saved session artwork without removing host protection. `--undo` now means the same narrow operation. Removing host identity protection requires `--remove-protection` explicitly.

## Upgrade

Close Omarchy windows normally and save your work first. From Plasma, use `ooc update --no-restart` to download and install the latest published package without automatically restarting sessions. Alternatively, download this release's package and install that downloaded file with `sudo pacman -U /path/to/package.pkg.tar.zst`.

The installed package must report 1.4.7 before relying on these fixes. Run `pacman -Q omarchy-on-cachyos`, then `ooc check`. Do not run Omarchy's upstream update commands on this combined installation.

## Tests and privacy

Regression tests cover removal failures, unreadable package state, falsely reported removal success, retained guards, empty-directory previews and artwork restoration without sudo. Existing fixture suites cover the previously discovered shortcut, browser, watchdog and packaging issues. These tests do not perform a real package removal or reboot.

Three fixtures contained a real machine identifier. They now use visibly synthetic values, with a regression check for that convention. Older history and the original 1.4.6 assets may still contain it. Older GitHub releases were privately archived and removed at the maintainer's request; source tags remain. Deletion cannot retract downloaded copies.
